Política de privacidade

Este pacote foi preparado como um site estático, sem cadastro ou serviços de rastreamento próprios.

Dados neste site

Os arquivos HTML, CSS e JavaScript desta edição não enviam dados a um servidor, não criam contas, não usam cookies de publicidade e não carregam bibliotecas ou fontes de terceiros. A busca de artigos é processada no próprio navegador.

Busca e navegação

Ao pesquisar, o termo pode aparecer na barra de endereço como parâmetro da página. A pesquisa é local: não é submetida a uma API do portal. O próprio navegador, o sistema operacional ou a hospedagem estática podem manter registros técnicos próprios; este site não controla esses serviços.

Contato

O formulário de contato só abre um aplicativo de e-mail quando o responsável configura um endereço no arquivo script.js. O envio depende do usuário e do programa de e-mail instalado; o portal não recebe nem armazena a mensagem.

Hospedagem e alterações

Se este site for publicado em um serviço de hospedagem, o provedor poderá tratar dados técnicos conforme a própria política. O responsável pelo portal deve atualizar este texto caso adicione analytics, publicidade, formulários conectados, integrações ou outros serviços.

Esta é uma declaração descritiva do pacote estático entregue, não uma avaliação jurídica. Revise-a para refletir a configuração efetiva antes de publicar.
